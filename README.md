# dbskill 全体系学习课程

> 边学边录视频讲解的学习项目。学习对象：[dontbesilent/dbskill](https://github.com/dontbesilent2025/dbskill)（CC BY-NC 4.0），本仓库为个人学习笔记与讲解，非官方文档，仅作学习交流。

## 这是什么

dbskill 是一套 **34 个技能 + 4200+ 知识原子** 的商业 AI 工具箱，核心哲学：**好的 AI 不回答问题，它消解问题**——8000+ 人付费问商业问题，只有 0.9% 被解答，99.1% 被消解，因为问题本身是错的。

本课程用 8 讲把它完整拆开讲透，每讲附录制脚本。

## 知识库结构（弹药库）

```
知识库/
├── 原子库/            # 4200+ 知识原子，按季度 JSONL（atoms_2024Q4 ~ 2025Q4）
├── Skill知识包/       # 26 个：每技能配套方法论 + 案例库
└── 高频概念词典.md
```

架构上最值得抄的一点：**提示词与知识包分离**——提示词管「怎么思考」，知识包管「用什么思考」，各自独立迭代。
