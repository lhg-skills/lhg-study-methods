# 第 5 讲：内容创作链（下）—— xhs-title 75 公式 + 检查链 + 公众号 HTML

> 🎬 录制钩子（前 10 秒）：「任何 AI 都能起标题，但只有这一套能让每个标题追溯到 75 个验证过的爆款公式编号。今天讲内容检查链全家桶。」

## 一、dbs-xhs-title：公式匹配器，不是标题生成器

**核心规则：每个标题都必须能追溯到公式编号，不准自由发挥。**

### 75 公式 × 12 类心理触发器

| 类型 | 编号 | 核心机制 |
|---|---|---|
| 认知冲突 | 1-6 | 打破已有认知 |
| 好奇缺口 | 7-12 | 信息不对称焦虑 |
| 恐惧/损失 | 13-20 | 不点就亏 |
| 身份代入 | 21-25 | "说的就是我" |
| 数字锚定 | 26-32 | 降低认知成本 |
| 结果承诺 | 33-40 | 具体结果+时间 |
| 社会证明 | 41-47 | 案例驱动 |
| 争议/挑衅 | 48-55 | 制造站队感 |
| 场景/条件 | 56-60 | 精准匹配状态 |
| 行动号召 | 61-66 | 推动行动 |
| 权威借力 | 67-71 | 名人/案例背书 |
| 互动/测试 | 72-75 | 激活参与感 |

### 工作流：话题+行业 → 匹配 → 定制 → Top 3

匹配逻辑：先判断话题属性（反常识→认知冲突型；内幕→好奇缺口型；避坑→恐惧损失型……），选 5-8 个公式，**至少覆盖 3 种类型**，不硬套。

每个输出：定制标题 + 公式编号 + 原始爆款举例 + 一句话解释。

### 标题质量 5 条铁律（最值得背下来）

1. **留悬念不说答案**：看完标题还需要点进来吗？答案说完=失败
2. **话题扩大不缩窄**：用普世词（赚钱、不上班）替换行业术语（知识付费、引流款）——缩窄=缩小流量池
3. **击中真实痛点**：「一人公司」是表象，「不上班」才是真实痛点
4. **张力检查 6 项至少中 2**：对比反差/具体数字/悬念/冲突争议/时间承诺/结果承诺
5. **小红书 ≤ 20 字**（含标点）

## 二、检查链三件套

### dbs-ai-check：22 个 AI 写作特征扫描

设计亮点——**默认只诊断不改写**，且不是机械打分，而是逐条**追问背后意图**：

- 特征「堵住所有反驳」→ 追问：「这些反驳哪个是你真被人问过的？只留那个，剩下的读者能感觉到是想象出来的」
- 特征「知识全部输出」→ 「这些术语哪个是你真用来想事情的？留那一个」
- 特征「匀速排比」→ 「哪句是你最想说的？打破均匀」
- 特征「情绪曲线太光滑」→ 「写的时候有没有哪你没完全想通？留着，别修圆」

**这是把「AI 味检测」做成了「写作教练」**——修圆的地方就是你没想通的地方。

### dbs-script-flow：逐字稿体检
检查段落衔接、信息密度、口播流畅度，**定位观众可能划走的具体位置**（精确到句）。

### dbs-content-risk-check：发布前安检
逐句检查标题/正文/图文字/字幕/口播的平台风险，输出风险点+改法。

## 三、dbs-wechat-html：排版最后一公里
Markdown → 公众号后台可直接粘贴的 HTML，15 种内置风格。技术含量不高但补齐了「写→发」的最后一环——**整条内容链闭环**。

## 四、内容链全景（把 4、5 两讲串起来）

```
选题 ──→ dbs-content（形式匹配+五维诊断）
         │
         ├─ 短视频 ──→ dbs-hook（开头）→ dbs-script-flow（逐字稿）→ dbs-content-risk-check
         │
         ├─ 小红书 ──→ dbs-xhs-title（标题）→ dbs-content-risk-check
         │
         └─ 公众号 ──→ dbs-wechat-html（排版）
                         
全程可选：dbs-ai-check（去AI味）→ dbs-resonate（共鸣断点）→ dbs-spread（传播复盘）
```

## ✍️ 本讲作业

1. 用 5 条铁律检查你过往 5 个标题，逐条打分
2. 用 dbs-ai-check 的 4 个追问自查你最近一篇文章：哪句是真被问过的？哪句是想象的？
