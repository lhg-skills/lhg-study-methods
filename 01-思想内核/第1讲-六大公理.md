# 第 1 讲：思想内核 —— 六大公理，所有技能的灵魂

> 🎬 录制钩子（前 10 秒）：「99% 的创业问题是心理问题——这句话不是鸡汤，是一套诊断系统的第一公理。今天讲 dbskill 的思想内核，学会了它，34 个技能你一看就懂。」

## 为什么先讲思想

dbskill 的每个技能都是三层结构：

```
第一层：核心公理（非谈判项）—— 世界观，决定诊断方向
第二层：工作流程（Phase 0 → N）—— 确定性步骤
第三层：禁止事项 —— 防止 AI 滑向庸俗回答
```

**公理是灵魂**。不懂公理直接用技能，只会得到一本正经的流程输出；懂了公理，你甚至能自己写出第 35 个技能。

## 六大公理（来自 dbs-diagnosis）

### 公理 1：商业模式是独立于人的客观存在

商业模式是一台有固定 input 要求的机器，人只是喂料员。财富几乎只关乎商业模式。

- **对「大佬」祛魅，对商业模式保持敬畏**
- 推论：研究一个人为什么赚钱，不要研究他的性格、运气、认知，去研究他的商业机器：input 是什么、转化链是什么、利润从哪来

### 公理 2：商业模式决定人的道德

好的商业模式逼你做好人，坏的商业模式逼你做恶人。道德是商业模式的副产品。

- **不要在坏的商业模式里做好人，要换商业模式**
- 这条公理解释了「为什么我这么努力还赚不到钱还很痛苦」——你可能不是人不行，是机器不行

### 公理 3：智力不直接变现，商业模式才变现

智商决定收入上限，商业模式决定收入下限。赚钱只需要执行力 + 商业模式，认知不是必要条件。

- 知识包里的原话：「AI 应用盈利第一定律：不告诉对方是 AI，依然让对方付钱」——顾客需要知道你是不是张三吗？

### 公理 4：流量不等于收入

只要商业模式好，赚多少钱和粉丝量没有关系。**99% 的情况下，流量越大越不赚钱。**

- 知识包原话：「如果不是直接讲赚钱方法的，点赞必小于 100」——点赞量是平台给的内容奖赏，不是商业价值
- 「没有转化设计的流量，只是给平台打工」

### 公理 5：定价即产品

定价本身就是产品设计。**引流款和利润款的价格差最好 10 倍**（5-15 倍区间），否则就不是两个产品。

- 9.9 和 19.9 不是两个产品，是同一个产品的两个焦虑
- 定价先于功能：先决定卖给谁、收多少钱，再决定做什么

### 公理 6：99% 的创业问题是心理问题

人们为了让自己「不行」而刻意选择「不知」。忙于赚钱却赚不到钱的人，并非不知道答案，而是**竭尽全力寻找绕过它的方法**。

- 这条公理直接孵化了 dbs-action（阿德勒执行力诊断）
- 也是「问题是被消解的，不是被解答的」这句话的根基

## 消解问题的方法论（对比传统咨询）

传统咨询：问题 → 分析 → 答案（问题是什么就答什么）

dbskill：问题 → **审查问题本身** → 大概率发现问题是错的 → 消解 → 重新钉一个真问题

案例（来自知识包）：
- 问：「为什么我做个人 IP 没流量？」
- 消解：「个人 IP」是模糊概念，你真正的问题可能是「我的产品没有转化路径，所以做内容也没有意义」——流量从来不是你的瓶颈，产品才是。原问题消失。
